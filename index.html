Criterion B: Design Planning

Core Features for Alpha

  • Vertical Webtoon scrolling interface.
  • Interactive progress bar tracking.
  • Mobile-friendly responsive layout.

What is NOT Included (Yet)

  • Full 16-panel story arc.
  • Advanced audio/visual effects.
  • Interactive dual-ending logic.

Success Criteria

  • Core scrolling feature works without crashing.
  • User can successfully complete the main reading action.
  • Basic interface is usable on mobile devices.

Criterion C: Alpha Version Prototype

Step-by-Step Functionality

  1. Access: The user opens the GitHub Pages link.
  2. Engagement: The user scrolls vertically to read the narrative.
  3. Visual Feedback: The top progress bar fills up as the user reads.
  4. Completion: The user reaches the alpha preview ending.

Development Evidence & Logic

System Logic

The site utilizes Vanilla JavaScript for the real-time progress bar and CSS Flexbox/Grid to maintain a viewport-locked layout for mobile consistency.

Tools & Technologies

The project is developed using HTML5 for structure, CSS3 for styling, and GitHub for version control and hosting.
